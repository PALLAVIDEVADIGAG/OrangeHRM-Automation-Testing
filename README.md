# OrangeHRM Automation Testing

## Project Overview

This repository contains Selenium WebDriver automation scripts developed for the OrangeHRM application using Java, TestNG, Maven, and the Page Object Model (POM) design pattern.

## Modules Covered

* Login Module
* PIM (Personnel Information Management) Module

## Framework

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)

## Automated Test Scenarios

### Login Module

* Valid Login
* Invalid Login
* Empty Field Validation
* Username Validation
* Password Validation
* Password Masking
* Dashboard Verification

### PIM Module

* Verify PIM Menu
* Navigate to PIM Module
* Verify Employee List
* Verify Employee Table
* Verify Records Found
* Verify Employee Row Count
* Compare Records Found with Employee Rows
* Verify Pagination
* Add Employee
